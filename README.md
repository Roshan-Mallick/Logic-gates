# Logic Gates in C

Learn and understand digital logic gates through simple C programs.

## Gates Included
- AND Gate
- OR Gate
- NOT Gate
- XOR Gate
- NAND Gate
- NOR Gate
- XNOR Gate

## Repository Structure

```
AND_gate.c
OR_gate.c
NOT_gate.c
...
```

## Purpose

This repository contains beginner-friendly implementations of logic gates in C to help understand their working and truth tables.

## How to Run

```bash
gcc OR_gate.c -o output
./output
```
